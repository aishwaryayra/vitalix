# vitalix
vitalix Anti-spoofing project is focused on developing a functional identity verification system with face liveness detection and anti-spoofing measures to prevent fraudulent attempts.Facial recognition has become one of the most widely used biometric authentication techniques, but it is highly vulnerable to spoofing attacks using photos, videos, or even 3D masks. To address this issue, we developed a real-time facial liveness detection system capable of differentiating between genuine human presence and spoofed inputs. The system was designed using Python, OpenCV, and TensorFlow/Keras, with deep learning models trained to analyze micro-textures and motion cues that distinguish real faces from fake ones. A custom dataset was prepared, including live face captures, printed images, video replays, and mask samples. Preprocessing techniques such as resizing, normalization, and augmentation were applied to ensure robustness, and the model was trained and optimized using a CNN architecture with binary classification.For real-time deployment, the system captured input from a webcam, detected the face region, and passed it to the liveness detection model for classification as either “real” or “spoof.” To strengthen security, we integrated challenge–response mechanisms such as blink detection and head movement tracking, ensuring that only genuine users could pass the test. The solution achieved 95% accuracy on test datasets and successfully detected spoofing attempts under different environmental conditions. The system was lightweight, capable of running on standard hardware with minimal latency, and included a simple Tkinter-based GUI for user interaction.
This project demonstrates the effectiveness of combining deep learning with motion-based verification for anti-spoofing applications. It provides a secure, real-time solution that can be integrated into authentication systems used in smartphones, banking, and IoT devices. While performance may vary in extremely low-light conditions or with high-quality spoofing media, the framework is scalable, adaptable, and offers strong potential for deployment in real-world security systems.
